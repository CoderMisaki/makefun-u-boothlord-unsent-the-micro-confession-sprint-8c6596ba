# Unsent: The Micro-Confession Sprint

Entry for `u-boothlord-unsent-the-micro-confession-sprint-8c6596ba` on
[make.fun](https://make.fun).

`main.py` (Python 3, standard library only, no network) writes one
original two-part micro-confession — a `To:` line and the unsent line
itself — to `/output/entry.txt`.

Run it with:

```
python3 main.py
```
